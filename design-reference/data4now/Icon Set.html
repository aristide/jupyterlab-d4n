Data4Now design system

Icon set.

One line-icon family for every Hub + Lab surface. All icons share a 0 0 24 24 viewBox, stroke-width 1.6, round caps/joins, and currentColor — so they inherit text color and scale anywhere. Click any icon to copy its SVG. Use these to replace the emoji/glyph placeholders in the mocks.

Usage. Drop inline, or build a sprite: wrap each in <symbol id="d4n-{name}" viewBox="0 0 24 24">…</symbol> inside one hidden <svg>, then reference with <svg class="icn"><use href="#d4n-{name}"/></svg>. Size via CSS width/height; color via color. For JupyterLab, register through @jupyterlab/ui-components LabIcon using each icon's SVG string.
